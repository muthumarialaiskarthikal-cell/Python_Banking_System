
# Python Banking Management System

## Project Overview
This project is a menu-driven Banking Management System developed using Python and Object-Oriented Programming (OOP).

It allows users to create bank accounts, deposit money, withdraw money, check balance, and view transaction history.

## Features
- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Account number verification

## OOP Concepts Used
1. Class and Objects
2. Constructor
3. Encapsulation
4. Inheritance
5. Methods
6. Abstraction

## Technologies Used
- Python 3
- GitHub
